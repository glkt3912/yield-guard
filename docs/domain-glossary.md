## 1. 基本概念

### 不動産投資の3大リスク

| リスク | 内容 | Yield-Guard での対応 |
|--------|------|----------------------|
| **空室リスク** | 入居者がいない期間の家賃収入ゼロ | 空室率パラメータ・ストレステスト |
| **金利リスク** | 変動金利上昇による返済額増加 | 変動金利スケジュール・金利ストレス |
| **流動性リスク** | 売りたい時に売れない・価格が下落する | 出口戦略シミュレーション・モンテカルロ |

### キャッシュフロー（CF）の種類

不動産投資では「利益」と「手元現金」が乖離することが多い。3種類を混同しないことが重要。

| 種類 | 定義 | 特徴 |
|------|------|------|
| **税引前CF** | 実効賃料 − ローン返済額 − 経費 | 現金ベース。帳簿上の損益と異なる |
| **税引後CF** | 税引前CF − 所得税 | 投資家の実際の手取り |
| **累積CF** | 税引後CFの年次合計 | 投資回収の進捗を示す |

> **なぜ乖離するか**: 減価償却費は「帳簿上の経費」だが現金は出ていかない。逆に元金返済は現金が出ていくが経費にならない。この差がデッドクロスの原因になる（→ [4. 税務指標](#4-税務指標節税と落とし穴)）。

### NOI（Net Operating Income／純営業利益）

```
NOI = 実効賃料（年間） − 運営経費
    = 月額賃料 × 12 × (1 − 空室率) − 年間経費
```

**なぜ重要か**: 銀行の融資審査（DSCR計算）と売却価格試算（収益還元法）の両方で基点となる指標。ローン返済を含まないため、物件そのものの収益力を示す。

### 総投資額と諸経費率

```
総投資額 = (土地価格 + 建物価格) × (1 + 諸経費率)
```

諸経費率の標準は **7%** で、内訳は以下の通り。

| 費目 | 割合の目安 |
|------|----------|
| 仲介手数料 | 物件価格の約3% + 6万円（税込） |
| 印紙税 | 0.002〜0.02%（金額段階別） |
| 登録免許税 | 土地2.0%・新築建物0.15%・中古建物2.0% |
| 不動産取得税 | 評価額×50%×3%（土地）、評価額×3%（建物） |
| 固定資産税精算 | 引渡し日〜年末分の日割り |

> 詳細な計算仕様は [`backend/internal/domain/acquisition_costs.go`](../backend/internal/domain/acquisition_costs.go) を参照。

## 2. 収益性指標

### 表面利回り vs 実質利回り

最も基本的な収益指標だが、**「表面」は楽観値、「実質」が実態**。

```
表面利回り（GrossYield） = (月額賃料 × 12) / 総投資額

実質利回り（NetYield）   = (月額賃料 × 12 × (1 − 空室率) − 年間経費) / 総投資額
```

| 指標 | 意味 | 限界 |
|------|------|------|
| 表面利回り | 満室・経費ゼロ想定の上限値 | 楽観的すぎる。比較用にのみ使う |
| 実質利回り | 空室・経費を反映した実態 | ローン返済・税金は含まない |
| CF利回り | ローン返済後の手取り率 | 投資家の実際の収益率 |

**業界水準**: 首都圏の中古アパートで表面利回り6〜10%が一般的。ただし表面利回りが高い物件は空室リスクや修繕リスクが高い場合が多い。

### 8%境界線

Yield-Guard 固有の判断基準。**表面利回り8%を下回る場合**、ツールは「達成に必要な土地価格・建築費の削減幅」を逆算して表示する。

```
必要月額賃料 = 総投資額 × 0.08 / 12
コスト削減額 = 総投資額 − (月額賃料 × 12 / 0.08)
```

8%の根拠: 空室率5%・経費率20%・金利1.5%を前提に、税引後キャッシュフローが正になる最低ラインとして設定。

### IRR（内部収益率）

```
NPV(IRR) = 0
         = -初期投資 + Σ(年次CF / (1+IRR)^t) + 売却純収入 / (1+IRR)^n
```

**何を意味するか**: 「この投資は年率何%の複利運用と等価か」。銀行金利・株式インデックスと直接比較できる唯一の指標。

| IRR水準 | 評価 |
|---------|------|
| < 0% | 損失確定 |
| 0〜3% | 預金水準（リスクに見合わない） |
| 3〜6% | 不動産投資として標準的 |
| 6%超 | 優良物件 |

**限界**: 計算に売却価格（収益還元法での仮定値）を含むため、出口利回りの仮定次第で大きく変わる。

### NPV（正味現在価値）

```
NPV = -初期投資 + Σ(年次CF / (1+割引率)^t) + 売却純収入 / (1+割引率)^n
```

**IRRとの使い分け**: IRRは「投資効率の相対評価」、NPVは「絶対的な富の増加額」。  
NPV > 0 なら割引率（要求利回り）を超える収益が期待できる。

> 計算実装は [`backend/internal/domain/investment.go`](../backend/internal/domain/investment.go) の `CalcIRR()` / `CalcNPV()`。

## 3. ローン・資金調達指標

### LTV（Loan to Value／ローン・トゥ・バリュー）

```
LTV = 借入額 / 総投資額 × 100（%）
```

**安全水準の目安: 70%以下**

| LTV | 意味 | リスク |
|-----|------|--------|
| 〜50% | 保守的 | 低い。価格下落に強い |
| 50〜70% | 標準的 | バランス良い |
| 70〜80% | やや積極的 | 価格下落時に逆ザヤリスク |
| 80%超 | 高リスク | 売却時に残債超過（オーバーローン）の危険 |

Yield-Guard では50/60/70/80/90%の5段階でLTV感度分析を表示し、各LTVでのDSCR・CFへの影響を確認できる。

### DSCR（Debt Service Coverage Ratio／借入金償還余裕率）

```
DSCR = NOI / 年間返済額（元金 + 利息）
```

**銀行の融資審査における最重要指標**。

| DSCR | 意味 |
|------|------|
| < 1.0 | 家賃だけでは返済できない（要追加資金） |
| 1.0〜1.2 | 余裕なし。空室で即座に資金不足 |
| 1.2〜1.5 | 一般的に融資可能ラインの下限 |
| 1.5超 | 余裕あり。追加融資も通りやすい |

> **銀行が1.25倍以上を求める理由**: 空室率が突然5%増加しても返済に支障が出ないバッファとして。

### 元利均等返済 vs 元金均等返済

| 方式 | 特徴 | デッドクロスへの影響 |
|------|------|---------------------|
| **元利均等**（等額返済） | 毎月の返済額が一定。初期は利息が大きく元金が少ない | デッドクロスが早く来やすい |
| **元金均等**（元金固定） | 毎月の元金返済が一定。初期返済額は大きいが後半減る | 初期に元金を多く返すためデッドクロスが遅れる |

**総利息の比較**: 同じ借入条件なら元金均等の方が総利息は少ない。ただし初期の返済負担が大きい。

### 変動金利リスク

Yield-Guard では `RateAdjustmentSchedule`（金利変動スケジュール）を指定可能。「5年後から+0.5%」などの段階的金利上昇を年次シミュレーションに組み込む。

```
例: 当初2%、5年後から2.5%、10年後から3%
→ 各年の返済額が自動的に再計算される
```

金利1%上昇が月額返済額に与える影響（3,000万円・35年ローンの場合）: 約8,000〜10,000円/月の増加。

## 4. 税務指標（節税と落とし穴）

### 減価償却の仕組み

不動産投資の節税効果の核心。**建物価格を法定耐用年数で割った額を毎年「経費」として計上できる**が、実際の現金流出はない。

```
年間減価償却費（定額法） = 建物取得価額 / 法定耐用年数
```

**「帳簿赤字・現金黒字」が節税になる理由**:

```
帳簿上の収支 = 家賃収入 − 利息 − 減価償却費 − 経費  → 赤字になりやすい
実際の現金   = 家賃収入 − 元利返済額 − 経費        → 黒字になりうる
```

帳簿赤字を給与所得と損益通算 → 所得税・住民税が減少 → 節税効果。

### 定額法 vs 定率法

| 方式 | 対象 | 特徴 |
|------|------|------|
| **定額法** | 個人投資家（必須） | 毎年一定額を償却。シンプル |
| **定率法** | 法人投資家 | 初期に大きく償却。前半の節税効果が大きい |

> **根拠**: 所得税法施行令第120条・第120条の2により、個人の建物は定額法のみ適用。

### 法定耐用年数 / 残存耐用年数

| 構造 | 法定耐用年数 |
|------|------------|
| 木造 | 22年 |
| 軽量鉄骨（3mm以下） | 19年 |
| 軽量鉄骨（4mm超） | 27年 |
| 重量鉄骨 | 34年 |
| RC造（鉄筋コンクリート） | 47年 |
| SRC造（鉄骨鉄筋コンクリート） | 47年 |

> **根拠**: 減価償却資産の耐用年数等に関する省令（別表第一）

**中古物件の残存耐用年数（簡便法）**:

```
経過年数 < 法定耐用年数の場合:
  残存 = (法定 − 経過) + 経過 × 0.2  （端数切捨て）

経過年数 ≥ 法定耐用年数の場合:
  残存 = 法定 × 0.2  （最低2年）
```

**例**: 築25年の木造（法定22年）→ 22 × 0.2 = 4年（最低2年以上なのでOK）

耐用年数が短い中古物件は**短期間で減価償却を完了できる**ため、前半の節税効果が大きい一方、償却完了後はデッドクロスに突入しやすい。

### 課税所得と損益通算

```
課税所得 = 実効賃料 − 利息 − 減価償却費 − 経費
```

**初期年度が赤字になりやすい理由**: ローン初期は利息が大きく、かつ耐用年数が短い中古物件は減価償却費も大きいため、課税所得がマイナスになる。この「不動産所得の赤字」を給与所得と合算（損益通算）することで節税できる。

**Yield-Guard での扱い**: `IncomeTaxRate`（実効税率）を入力すると、課税所得×実効税率として所得税を計算。税引後CFに反映される。

### デッドクロス

**定義**: 元金返済額が減価償却費を上回る年から発生。

```
デッドクロス発生 = 元金返済額 > 減価償却費
```

**黒字倒産が起きるメカニズム**:

```
帳簿上の利益  = 家賃 − 利息 − 減価償却 − 経費  → 正（所得税が発生）
実際の現金CF  = 家賃 − 元利返済 − 経費 − 所得税 → 負（現金が足りない）
```

ローン返済が進むにつれ利息が減り元金返済が増える。一方、減価償却費は一定（定額法）か減少する。この2本が交差するのがデッドクロス。

**3つの対策**:

| 対策 | 内容 |
|------|------|
| ① 繰上返済 | 元金を早期返済してローン残高を減らす |
| ② 物件追加購入 | 新たな減価償却資産を積み上げて償却費を増やす |
| ③ キャッシュ積立 | デッドクロス期間の税負担に備えて現金確保 |

> 詳細な判定ロジックは [`docs/domain-depreciation-dead-cross.md`](./domain-depreciation-dead-cross.md) を参照。

## 5. 取得時コスト

### 諸経費の内訳

物件購入時に発生する一時的なコスト。総投資額の**約7%**が目安。

#### 仲介手数料

> **根拠**: 宅地建物取引業法第46条（報酬告示）

```
価格 ≤ 200万円:    価格 × 5% × 1.1（消費税）
価格 ≤ 400万円:    価格 × 4% + 2万円 × 1.1
価格 > 400万円:    価格 × 3% + 6万円 × 1.1
```

#### 印紙税

> **根拠**: 印紙税法 別表第一

売買契約書・金銭消費貸借契約書に貼付。1,000万〜5,000万円の契約で2,000円。

#### 登録免許税

> **根拠**: 登録免許税法・租税特別措置法

| 登記種別 | 税率 | 備考 |
|---------|------|------|
| 土地所有権移転 | 評価額 × 2.0% | 特例なし |
| 新築建物（保存登記） | 評価額 × 0.15% | 軽減措置（〜2027年3月） |
| 中古建物（移転登記） | 評価額 × 2.0% | 要件次第で0.3%に軽減 |
| 抵当権設定 | 融資額 × 0.4% | — |

#### 不動産取得税

> **根拠**: 地方税法・租税特別措置法（特例3%は〜2027年3月）

```
土地: 固定資産税評価額 × 50% × 3%
建物: 固定資産税評価額 × 3%
```

#### 固定資産税の日割り精算

引渡し日〜12月31日分を買主が負担。取得時の現金流出として計算に含める。

> 計算実装は [`backend/internal/domain/acquisition_costs.go`](../backend/internal/domain/acquisition_costs.go) / [`property_tax.go`](../backend/internal/domain/property_tax.go)。

### 固定資産税の小規模住宅用地特例

200㎡以下の住宅用地は固定資産税が大幅に軽減される。

```
土地200㎡以下（小規模住宅用地）:
  固定資産税 = 評価額 × 1.4% ÷ 6
  都市計画税 = 評価額 × 0.3% ÷ 3

土地200㎡超（一般住宅用地）:
  固定資産税 = 評価額 × 1.4% ÷ 3
  都市計画税 = 評価額 × 0.3% × 2/3
```

## 6. 出口戦略指標

### 収益還元法（Direct Capitalization）

不動産の売却価格を「その物件が生み出す収益」から逆算する手法。

```
売却価格 = NOI（売却時点の想定） / 目標利回り（ExitYieldTarget）
```

**例**: NOI 200万円、目標利回り6% → 売却価格 = 200万 ÷ 0.06 = 約3,333万円

**なぜ「購入価格-売却価格」ではないか**: 不動産の市場価格は「その物件が生み出す家賃収入の現在価値」で決まる。築年数が経つと家賃が下落し、それに連動して売却価格も下がる。

目標利回りを低く設定するほど高値売却を想定することになるため、**保守的な試算では6〜7%**を使う。

### 譲渡所得の計算

```
譲渡所得 = 売却価格 − 売却費用 − 取得費

取得費     = 土地取得価額 + 建物簿価（建物取得価額 − 累計減価償却額）+ 取得時諸経費
売却費用   = 仲介手数料（売却価格 × 3% + 6万円 × 1.1）
```

**注意**: 取得費に含まれる建物価額は**税務簿価**（購入時から減価償却を引いた金額）であり、購入時の建物価格ではない。長期保有で減価償却が進むほど取得費が下がり、譲渡所得（課税対象）が増える。

### 短期 vs 長期譲渡税率

| 保有期間 | 税率 | 備考 |
|---------|------|------|
| 5年以下（短期譲渡） | 39.63% | 所得税30.63% + 住民税9% |
| 5年超（長期譲渡） | 20.315% | 所得税15.315% + 住民税5% |

> **根拠**: 租税特別措置法第31条（長期）・第32条（短期）

保有5年を超えると税率が約半分になるため、**5年未満での売却は税負担が大きい**。

> **注意**: 判定基準は売却した年の1月1日時点での保有年数。12月に購入し翌々年1月に売却しても「1年未満」扱いになることがある。

### 最終手残り（ExitTotalEquity）

```
売却手取り = 売却価格 − 売却費用 − 譲渡所得税 − ローン残高
最終手残り  = 売却手取り + 累積キャッシュフロー
```

**投資判断での使い方**: 最終手残り ÷ 自己資金 = 実質的な投資倍率。保有年数を考慮したIRRと合わせて評価する。

> 詳細な計算仕様は [`docs/domain-exit-strategy.md`](./domain-exit-strategy.md) を参照。

## 7. 投資適地スコア

### スコア構成（0–100点）

基本点50点から、11種類のMLIT（国土交通省）APIデータに基づく指標で加減点する。

| カテゴリ | 指標 | 加減点 |
|---------|------|--------|
| **人口動態** | 30年後人口変化率（XKT013） | −15〜+15点 |
| **交通利便性** | 最寄り駅乗降客数（XKT015） | 0〜+20点（20万人/日で満点） |
| **都市計画** | 市街化区域（都市計画法） | +10点 |
| **立地適正化** | 居住誘導区域（XKT003） | −5〜+10点 |
| **ハザードリスク** | 洪水・高潮・津波・土砂崩れ（XKT025〜029） | 各−5点（最大−20点） |
| **液状化リスク** | 液状化危険度（XKT031） | −10〜0点 |
| **盛土リスク** | 大規模盛土造成地（XKT020） | −5〜0点 |
| **災害履歴** | 過去の災害記録（XST001） | −10〜−2点（年数重み: 10年以内-10、30年以内-5、30年超-2） |
| **地価トレンド** | 都道府県別坪単価変化率（MLIT土地取引） | −10〜+10点（直近2年 vs 3〜4年前の中央値比較） |

### グレードの目安

| スコア | グレード | 投資判断の参考 |
|--------|---------|--------------|
| 80点以上 | 優良 | 立地リスクは低い。物件・価格の精査に集中できる |
| 65〜79点 | 良好 | 軽微なリスクあり。詳細確認を推奨 |
| 50〜64点 | 普通 | 複数のリスク要因が存在。ハザード詳細を要確認 |
| 35〜49点 | 注意 | 明確なリスク要因あり。専門家への相談を推奨 |
| 34点以下 | 要注意 | 重大なリスク要因あり。投資判断には慎重な調査が必要 |

### 5軸レーダーチャートの読み方

フロントエンドでは5カテゴリに集約して表示する。

| 軸 | 含まれる指標 |
|----|------------|
| 人口動態 | 人口変化率スコア |
| 交通利便性 | 駅乗降客数スコア |
| 都市計画 | 市街化区域・居住誘導区域 |
| ハザード | 洪水・高潮・津波・土砂崩れ |
| 地盤 | 液状化・盛土・災害履歴 |

各軸が外側（高得点）に近いほど優良。内側に凹んでいる軸が投資上の懸念ポイント。

## 8. リスク定量化

### ストレステスト（6パターン）

単一シナリオではなく、悪条件を組み合わせた複数シナリオでキャッシュフローを検証する。

| パターン | 空室率変化 | 金利変化 | 賃料変化 |
|---------|-----------|---------|---------|
| 標準 | 0% | 0% | 0% |
| 空室悪化 | +10% | 0% | 0% |
| 金利上昇 | 0% | +1.5% | 0% |
| 賃料下落 | 0% | 0% | −10% |
| 複合（中程度） | +5% | +1.0% | −5% |
| 複合（最悪） | +15% | +2.0% | −15% |

**なぜ最悪シナリオを見るか**: 不動産投資は10〜30年のコミットメントであり、その間に複数のリスクが同時発生することがある（例: 景気後退→空室増加+金利上昇+賃料下落）。

### モンテカルロシミュレーション

確率分布を使って1,000回以上のシミュレーションを実行し、IRR・最終手残りの分布を可視化する。

```
各試行: 空室率・金利に正規分布の乱数を加えてAnalyze()を実行
結果:   IRRのP10（悲観）/ P50（中央値）/ P90（楽観）を表示
```

**P10（悲観シナリオ）で意思決定すべき理由**: 投資家の損失忌避性（プロスペクト理論）に基づき、「最悪でも耐えられるか」が重要。P50（期待値）で判断すると、リスクを過小評価しやすい。

**デッドクロス発生率**: シミュレーション全体のうち何%でデッドクロスが発生するかを確認することで、空室・金利変動を加味した現実的なリスク確率を把握できる。

> 計算実装は [`backend/internal/domain/montecarlo.go`](../backend/internal/domain/montecarlo.go)。

### リフォームROI（投資対効果）

リフォームを行う前に「回収年数」と「税効果」を試算する。

```
回収年数 = 総工事費 / (月額賃料増加分 × 12)
```

**費用分類が税効果に影響する**:

| 分類 | 条件 | 税務処理 |
|------|------|---------|
| **修繕費** | 工事1件が60万円以下 または 機能維持目的 | その年度に全額経費化 → 即時節税 |
| **資本的支出** | 工事1件が60万円超 かつ 機能向上目的 | 耐用年数で減価償却 → 節税は分割 |

修繕費は即時節税効果が大きいが、資本的支出は中長期的な資産価値向上を狙う。

> 計算実装は [`backend/internal/domain/renovation.go`](../backend/internal/domain/renovation.go)。

## 9. 物件属性・法的制約

### 再建築不可

**定義**: 現行法令の基準を満たしていないため、建物を取り壊した後に新たな建物を建てられない土地・物件。

**発生原因（接道義務違反）**:

建築基準法第43条により、建築物の敷地は **幅員4m以上の道路に2m以上接する** 必要がある（接道義務）。以下のいずれかに該当すると再建築不可になる。

| パターン | 内容 |
|---------|------|
| 幅員不足 | 接している道が建築基準法上の道路（4m以上）でない |
| 間口不足 | 道路への接面が2m未満（旗竿地など） |
| 囲繞地 | 他の土地に四方を囲まれ道路に接していない |

**投資上の影響**:

| 観点 | 影響 |
|------|------|
| 融資 | 多くの金融機関が担保として認めない → 実質的に現金購入しか選択肢がない |
| 出口戦略 | 売却先が限定（現金購入者のみ）→ 流動性リスク大 |
| 修繕 | 大規模改修は可能だが建て替え不可 |
| 評価 | 市場価格の30〜50%程度に評価が低下することが多い |

**Yield-Guardでの注意**: 再建築不可物件を入力する場合、DSCR・LTV感度分析の結果が実態（融資不可）を反映しない。出口戦略の `ExitYieldTarget` を高め（7〜10%）に設定し、売却価格を保守的に試算すること。

---

### 接道義務

> **根拠**: 建築基準法第43条

建築物の敷地は建築基準法上の道路（原則幅員4m以上）に **2m以上** 接しなければならない。接道義務を満たさない場合、既存建物の維持はできるが建て替えが原則不可となる。

---

### 42条2項道路（みなし道路）

> **根拠**: 建築基準法第42条第2項

建築基準法施行（1950年）以前から存在する幅員4m未満の道路で、特定行政庁が指定したもの。「2項道路」とも呼ばれる。

**セットバック義務**: 2項道路に接する土地は道路中心線から **2m後退（セットバック）** させて建物・塀を建てることで再建築が可能になる。セットバック部分は建ぺい率・容積率の計算面積から除外される。

> **注意**: 道路の片側が河川・崖・線路等の場合は中心線基準が適用されず、反対側の道路端から **4m** のラインまで後退が必要になる（壁面後退距離が増大する）。購入前に特定行政庁または建築士への確認を推奨する。

| 投資上の影響 | 内容 |
|------------|------|
| 実効面積の減少 | セットバック後の建物面積が登記面積より小さくなる |
| 将来的な義務 | 建て替え時にセットバックが強制される |

---

### 既存不適格

**定義**: 建築当時は適法だったが、その後の法改正（建ぺい率・容積率変更、耐震基準改定など）により現行法に適合しなくなった建物。

**再建築時の制約**: 建て替えの際は現行法規に適合させる必要があるため、**同規模の建物を再建築できない**ケースがある。

| 投資上の影響 | 内容 |
|------------|------|
| 規模縮小リスク | 建て替えで床面積・収容戸数が減少する可能性 |
| 融資審査 | 耐震基準を下回る場合、住宅ローン・投資ローンの審査で不利 |
| 出口戦略 | 買い手が建て替えを想定する場合、評価額が下がる |

---

## 10. 瑕疵（物件の欠陥）

> **根拠**: 宅地建物取引業法第35条（重要事項説明）・民法第566条（契約不適合責任）

売主は既知の瑕疵を買主に告知する義務がある。未告知の瑕疵は **契約不適合責任**（知った時から5年・引渡しから10年）の対象となる。

### 瑕疵の4分類

| 種類 | 内容 | 具体例 |
|------|------|--------|
| **物理的瑕疵** | 建物・土地の物理的な欠陥 | 雨漏り・シロアリ被害・基礎ひび割れ・土壌汚染・アスベスト |
| **法律的瑕疵** | 法令上の制限・権利関係の問題 | 再建築不可・既存不適格・接道義務違反・建ぺい率超過・差押え |
| **心理的瑕疵** | 居住者に心理的抵抗を与える事情 | 自殺・他殺・孤独死（一定期間の告知義務あり）・忌避施設の近接 |
| **環境的瑕疵** | 周辺環境による問題 | 騒音・振動・異臭・電磁波・危険施設（ゴミ処理場・工場等）の近接 |

**投資上の影響**:

| 瑕疵の種類 | 収支への影響 |
|----------|------------|
| 物理的瑕疵 | 修繕費として投資計算に組み込む必要がある |
| 法律的瑕疵 | 出口戦略を根本的に制約する（再建築不可は特に深刻） |
| 心理的瑕疵 | 賃料が市場相場より10〜30%程度低下するケースが多い |
| 環境的瑕疵 | 入居者ターゲットが限定され空室率が上昇しやすい |

**Yield-Guardでの対応**: 瑕疵物件を評価する場合、以下のパラメータを保守的に設定すること。

- 心理的・環境的瑕疵: `MonthlyRent` を市場相場比で割り引き、`VacancyRate` を高めに設定
- 物理的瑕疵: リフォームROI機能で修繕費を計上してから収支計算を行う
- 法律的瑕疵（再建築不可等）: 出口利回り `ExitYieldTarget` を高め（7〜10%）に設定

## 11. 権利形態

### 所有権・借地権・地上権

| 権利 | 内容 | 特徴 |
|------|------|------|
| **所有権** | 土地・建物を完全に所有 | 標準的な投資形態。担保評価が最も高い |
| **借地権（賃借権）** | 地主から土地を借りて建物を所有 | 地代が発生。借地契約の期限・更新条件に注意 |
| **地上権** | 土地の上に建物・工作物を置く物権 | 賃借権より強い権利。地主の承諾なしに譲渡可能 |

> **根拠**: 借地借家法・民法第265条（地上権）

**借地権物件の投資上の影響**:

| 観点 | 影響 |
|------|------|
| 融資 | 担保評価が低い。借地権設定契約の内容によって融資不可の場合も |
| 出口 | 売却時に地主の承諾が必要（譲渡承諾料が発生することが多い） |
| 追加コスト | 地代（月額）・更新料・建替承諾料が継続的に発生 |
| 評価 | 所有権物件の60〜70%程度に評価されることが多い |

**Yield-Guardでの対応**: 借地権物件では地代を `OperatingExpenseRate`（運営経費率）に上乗せするか、固定経費として入力する。出口の `ExitYieldTarget` は所有権物件より高め（流動性低下分）に設定すること。

---

### 区分所有

マンション等の共同住宅における専有部分の所有形態。建物の区分所有等に関する法律（区分所有法）が適用される。

**投資固有のリスク**:

| リスク | 内容 |
|--------|------|
| 修繕積立金不足 | 大規模修繕時に一時金徴収（数十〜百万円/戸）が発生する可能性 |
| 管理規約の制限 | 第三者への賃貸を禁止・制限する管理規約が存在するケースがある |
| 管理組合の財政 | 管理費滞納・積立不足の管理組合は将来の修繕費リスクが高い |

---

## 12. 管理コスト・契約形態

### 管理費・修繕積立金（区分マンション）

| 費目 | 内容 | 月額目安 |
|------|------|---------|
| **管理費** | 共用部の清掃・設備維持・管理会社委託費 | 1〜3万円/戸 |
| **修繕積立金** | 将来の大規模修繕に備えた積立 | 1〜3万円/戸（築年数・管理状況で大幅に変動） |

**修繕積立金の問題点**:
- 新築時は低額に設定され、築年数とともに段階的に増額される（段階増額方式）
- 積立不足の場合、大規模修繕（外壁・屋上防水・エレベーター更新等）時に **一時金徴収** が発生する
- 購入時は重要事項説明書で積立金残高と修繕計画を必ず確認する

**Yield-Guardでの対応**: 管理費・修繕積立金の合計を `OperatingExpenseRate`（運営経費率）に組み込むか、年間経費として別途計上する。現況が低額でも将来の増額をストレステストで確認すること。

---

### サブリース契約

**定義**: サブリース会社（管理会社）が物件全体を一括で借り上げ、個々の入居者に又貸しする契約形態。

**メリット**:
- 空室リスクを軽減できる（保証賃料を受け取れる）
- 管理業務をアウトソースできる

**リスク**:

| リスク | 内容 |
|--------|------|
| **賃料減額リスク** | 一定期間後に保証賃料の減額を求められることが多い |
| **解約困難** | 借地借家法の適用により、オーナー側から解約することが困難なケースがある |
| **利回りの乖離** | 保証賃料は市場賃料の80〜90%程度。表面利回りが高く見えても実態は異なる |
| **倒産リスク** | サブリース会社倒産時に賃料が入らなくなる |

**Yield-Guardでの対応**: サブリース契約物件を評価する場合:
- `MonthlyRent` には保証賃料（市場賃料の80〜90%）を入力
- `VacancyRate` は0%（全室保証）で設定
- 将来の賃料減額リスクを反映するため `RentDeclineRate` を保守的に設定（例: 1.0〜2.0%/年）

## 13. 有資格者の役割と活用場面

Yield-Guard は投資判断の**補助ツール**であり、法的・税務的・建築的な最終判断には各分野の有資格者への相談が不可欠。以下に不動産投資で関わる主な資格と、ツール利用時に相談を要する場面を整理する。

### 資格別の役割と相談タイミング

| 資格 | 主な役割 | 相談が必要な場面 |
|------|---------|----------------|
| **宅地建物取引士**（宅建士） | 重要事項説明・売買契約の媒介 | 物件購入時の重要事項説明受領・契約書確認 |
| **不動産鑑定士** | 不動産の適正価格の評価・鑑定評価書作成 | 売買価格の妥当性検証・相続・裁判 |
| **一級・二級建築士** | 建物の設計・構造安全性の確認 | 既存不適格・違法建築の確認、大規模リノベーション設計 |
| **司法書士** | 登記手続き（所有権移転・抵当権設定）・権利関係の確認 | 決済・登記申請、権利関係が複雑な物件 |
| **税理士** | 確定申告（不動産所得）・節税対策の立案 | 減価償却・損益通算の処理、デッドクロス対策、法人化検討 |
| **弁護士** | 法的トラブルの解決・契約交渉 | 契約不適合責任の追及、立退き・明渡し交渉、サブリース解約 |

---

### Yield-Guardの出力と有資格者の関係

Yield-Guard が算出する各指標は「現実の融資・契約・税務」を直接保証するものではない。以下の対応関係を開発者・利用者が理解しておくことが重要。

| Yield-Guard の出力 | 実務上の確認先 |
|------------------|--------------|
| DSCR・LTV感度分析 | 実際の融資可否は金融機関と**司法書士**（担保設定）が判断 |
| 表面・実質利回り | 賃料相場の妥当性は**宅建士**または管理会社に確認 |
| 減価償却・課税所得 | 最終的な税額計算・節税スキームは**税理士**に依頼 |
| リフォームROI | 工事費用・建築基準法適合性は**建築士**に確認 |
| 出口売却価格（収益還元法） | 精度の高い査定・評価が必要な場合は**不動産鑑定士**に依頼 |
| 瑕疵・権利形態の影響試算 | 法律的瑕疵・権利リスクの解消は**弁護士**・**司法書士**に相談 |

---

### 宅建士の関与が法的に必須の場面

> **根拠**: 宅地建物取引業法第35条・第37条

不動産売買における以下の行為は、**宅地建物取引士の記名・押印**が法律上義務付けられており、無資格者による代行は違法。

- **重要事項説明**（第35条）: 契約前に買主へ物件・権利関係・法令制限等を書面で説明する行為
- **37条書面（契約書）への記名**（第37条）: 売買契約書・賃貸借契約書への宅建士の記名

**投資家として注意すべき点**: 個人間売買（業者不介在）では重要事項説明が省略されるケースがある。再建築不可・心理的瑕疵・境界未確定など重大なリスクが告知されない可能性があるため、個人間売買では別途専門家調査（ホームインスペクション等）を推奨する。

---

### 法人化と税理士

不動産投資の規模拡大に伴い、**個人→法人化**を検討する段階で税理士への相談が特に重要になる。

| 検討タイミング | 内容 |
|-------------|------|
| 課税所得が**900万円超**になる見込み | 法人税率が個人の最高税率を下回るため節税効果が出やすい |
| 物件を**3棟以上**保有 | 事業規模認定により経費算入範囲が拡大する |
| **相続対策**を兼ねる場合 | 法人化による株式評価減・贈与計画の立案が必要 |

> Yield-Guard の `IncomeTaxRate`（実効税率）入力値は、法人化後の税率に変更することで法人スキームの収支比較にも活用できる。
